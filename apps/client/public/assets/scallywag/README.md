# Scallywag art (runtime assets)

Scallywag - Ships and Scallywag - Water and Islands, by Pixel Carvel,
distributed by Foozle (https://foozlecc.itch.io/). CC0 1.0: free to use and
modify, attribution not required (see https://creativecommons.org/publicdomain/zero/1.0/).

Only the sheets the game loads are copied here; the Aseprite sources stay in the
original download.

- `ships.png` (720x672): hulls in 3 sizes, 5 colours (+ grey), sails in 6 colours,
  yards, flag symbols, cannons, effects. Frames are cut in
  `src/phaser/assets/scallywag.ts` from measured boxes.
- `water-islands.png` (384x144): 16x16 tiles for islands, shallows, water,
  stones, palms, planks and chests.
